# Development Roadmap

## Completed in this starter
- Flask application structure and configuration.
- Student registration, login and logout.
- Password hashing and role-based route checks.
- Student profile editing.
- Company creation and company directory.
- Job creation and job listing.
- Sample eligibility matching and duplicate application prevention.
- Student application tracking and administrator status updates.
- MySQL schema reference and setup documentation.

## Recommended next steps
- Add automated tests for registration, authorization, eligibility and duplicate applications.
- Add form validation and clearer error handling for every field.
- Add search/filter/pagination for jobs and student records.
- Add resume upload with file type/size validation and private storage.
- Add placement-record create/edit screens and reports.
- Add email notifications and audit logs.
- Add database migrations (Flask-Migrate/Alembic).
- Review security, privacy and accessibility before deployment.
